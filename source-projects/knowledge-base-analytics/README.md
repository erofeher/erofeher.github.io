# Knowledge Base Analytics Dashboard

Portfolio project built with React, TypeScript, Material UI, React Query, Axios, Recharts, Jest and React Testing Library.

## Features
- KPI overview and content health metrics
- Article performance and content status charts
- Search and combined filters
- Responsive article table
- Loading, error and empty states
- REST/Axios adapter with simulated local data
- Automated component test

## Run
`npm install`
`npm run dev`

## Validate
`npm run build`
`npm test`

All data is simulated for portfolio use.
