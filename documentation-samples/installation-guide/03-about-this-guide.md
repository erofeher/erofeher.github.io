# About This Guide

[← Back to Table of Contents](index.html)

---

This guide provides step-by-step procedures for installing and configuring the
**Contoso Platform**. It is intended for use by system administrators and implementation
engineers who are responsible for deploying the solution in a customer environment.

The guide includes:

- **[Installation Overview](04-installation-overview.html)** – a summary of the solution
  components and the overall installation process.
- **[Solution Architecture](05-solution-architecture.html)** – a high-level diagram and
  description of how the components communicate with each other.
- **[Prerequisites and Preparation](06-prerequisites.html)** – the list of required
  preinstalled software, supported versions, and permissions.
- **[Preparing the Configuration Files](07-preparing-configuration-files.html)** –
  instructions for editing and encrypting the installer configuration files.
- **[Configuring the Application](08-configuring-the-application.html)** – reference
  tables describing the application configuration parameters.
- **[Running the Installer](09-running-the-installer.html)** – instructions for running
  the installer from the command line.
- **[Verifying the Installation](10-verifying-the-installation.html)** – a checklist for
  confirming that the installation completed successfully.

## Documentation Disclaimer

This document may describe features that require a separate license and are not part of
a standard product license. For information about licensing, contact your account
representative.

The visibility of certain features depends on user roles and permissions. This guide
describes such features, but they may not be visible in every deployment.

Examples included in this document are for the purpose of illustration and reference
only. Screenshots may differ from your actual environment, depending on configuration
and browser used.
