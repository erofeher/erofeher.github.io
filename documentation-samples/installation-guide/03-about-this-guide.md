# About this guide

[← Back to table of contents](index.html)

---

This guide provides step-by-step procedures for installing and configuring the Contoso
Platform. It's for system administrators and implementation engineers who deploy the
solution in a customer environment.

This guide includes:

- **[Installation overview](04-installation-overview.html)**: A summary of the solution
  components and the overall installation process.
- **[Solution architecture](05-solution-architecture.html)**: A high-level diagram and
  description of how the components communicate with each other.
- **[Prerequisites and preparation](06-prerequisites.html)**: The list of required
  preinstalled software, supported versions, and permissions.
- **[Prepare the configuration files](07-preparing-configuration-files.html)**:
  Instructions for editing and encrypting the installer configuration files.
- **[Configure the application](08-configuring-the-application.html)**: Reference tables
  that describe the application configuration parameters.
- **[Run the installer](09-running-the-installer.html)**: Instructions for running the
  installer from the command line.
- **[Verify the installation](10-verifying-the-installation.html)**: A checklist for
  confirming that the installation completed successfully.

## Documentation disclaimer

This document might describe features that require a separate license and aren't part
of a standard product license. For licensing information, contact your account
representative.

Feature visibility depends on user roles and permissions. This guide describes such
features, but they might not be visible in every deployment.

The examples in this document illustrate structure and format only. Screenshots might
differ from your actual environment, depending on your configuration and browser.
