# Contoso Platform Installation Guide (Sample Template)

> **This is a sample template.** It shows the typical structure, tone, and formatting of
> an enterprise software installation guide. All product names, parameters, file names,
> and screenshots are fictitious. You can share it publicly and reuse it as a starting
> point for any product's installation guide. It isn't tied to any specific NICE
> Actimize product or real configuration data.

## About this sample

This template follows the general structure of a typical installation guide: overview,
prerequisites, installation, configuration, and verification. All the content uses a
fictitious product, Contoso Platform, and a fictitious company, Contoso Inc.

Use this template to:

- Show a customer, partner, or new writer what an installation guide looks like.
- Bootstrap a new installation guide for a different product.
- Demonstrate documentation structure and style without exposing real product
  internals.

## How to reuse this template

1. Copy this folder to your new project.
2. Find and replace `Contoso Platform` and `Contoso Inc.` with your real product and
   company name.
3. Replace the fictitious parameter tables, commands, and diagrams in each topic with
   your real content.
4. Update the [revision history](02-revision-history.html) table with your own entries.
5. Delete this "How to reuse this template" section before you publish the guide.
