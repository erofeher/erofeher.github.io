# Contoso Platform Implementer Guide (Sample Template)

> **This is a sample template.** It shows the typical structure, tone, and formatting of
> an enterprise software implementer guide. All product names, rule names, function
> names, and parameters are fictitious. You can share it publicly and reuse it as a
> starting point for any product's implementer guide. It isn't tied to any specific NICE
> Actimize product, business rule, or detection logic.

## About this sample

This template follows the general structure of a typical implementer guide: overview,
data integration, customization, business logic, detection rules, scoring, and
validation. All the content uses a fictitious product, Contoso Platform, and a
fictitious company, Contoso Inc.

This guide is a companion to the
[Contoso Platform Installation Guide](../installation-guide/index.html) sample.
The Installation Guide covers how to deploy the software. This Implementer Guide covers
how to configure it for a specific customer environment.

Use this template to:

- Show a customer, partner, or new writer what an implementer guide looks like.
- Bootstrap a new implementer guide for a different product.
- Demonstrate documentation structure and style without exposing real business logic,
  detection rules, or scoring algorithms.

## How to reuse this template

1. Copy this folder to your new project.
2. Find and replace `Contoso Platform` and `Contoso Inc.` with your real product and
   company name.
3. Replace the fictitious fields, functions, rules, and thresholds in each topic with
   your real configuration content.
4. Update the [revision history](02-revision-history.html) table with your own entries.
5. Delete this "How to reuse this template" section before you publish the guide.
